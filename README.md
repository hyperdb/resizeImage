# resizeImage

指定したディレクトリにある PNG 画像を一括でリサイズするツールです。
PNG 画像は指定した幅と高さにリサイズされ、指定した出力ディレクトリに保存されます。
出力ディレクトリが存在しない場合は自動的に作成されます。
なお、PNG 画像は背景が透過であることが前提です。

## 使い方

```bash
python resize.py <入力ディレクトリ> --output <出力ディレクトリ> --width <幅> --height <高さ>
```

-   `<入力ディレクトリ>`: リサイズしたい PNG 画像が保存されているディレクトリのパスを指定します。
-   `--output <出力ディレクトリ>`: リサイズ後の画像を保存するディレクトリのパスを指定します。デフォルトは `./outdir` です。
-   `--width <幅>`: リサイズ後の画像の幅をピクセル単位で指定します。デフォルトは `1280` です。
-   `--height <高さ>`: リサイズ後の画像の高さをピクセル単位で指定します。デフォルトは `720` です。
